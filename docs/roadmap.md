# Roadmap

## Phase 1 - Core platform

- Node registry.
- Sensor registry.
- MQTT ingestion.
- Dashboard.
- JWT/RBAC.
- PostgreSQL/TimescaleDB schema.

## Phase 2 - Advanced dashboards

- Aggregated views.
- Custom dashboards.
- User-defined panels.
- Exportable reports.

## Phase 3 - Alerts and automation

- Full alert engine.
- Notification channels.
- Escalation policies.

## Phase 4 - Remote commands

- Command approval workflows.
- Command result tracking.
- Device configuration sync.

## Phase 5 - Firmware management

- Firmware artifact registry.
- Rollout management.
- Device compatibility tracking.

## Phase 6 - Multi-site / multi-tenant

- Tenant table.
- Tenant-scoped IDs and RBAC.
- Isolated topic namespaces.

## Phase 7 - High availability

- EMQX cluster.
- API horizontal scaling.
- Read replicas.
- Queue-based ingestion.
- Disaster recovery drills.
